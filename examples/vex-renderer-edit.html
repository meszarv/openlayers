Editing interactions are ready. Select features to translate or drag their vertices.

When Vex is enabled, every feature is recorded exactly once per rotation and then reused for panning and zooming via setSceneView(). Toggle the switch to compare the experimental renderer with the standard Canvas 2D path.

Use the buttons to append new plazas (vectorLayer.addFeatures()) or clear the layer entirely (vectorLayer.clear()) and observe how the cached instructions respond. Added plazas define their own styles via feature.setStyle() so you can verify that feature-level styling is respected.
