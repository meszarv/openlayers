--- layout: example.html title: Vex Vector Renderer (experimental) shortdesc: Demonstrates caching vector instructions once per rotation with the Vex mock engine. docs: > This example shows how to opt-in to the experimental Vex renderer for vector layers. Features are recorded once for the current view rotation and then reused for subsequent pan and zoom updates via `setSceneView()`. The scene is rebuilt only when the view rotation or device pixel ratio changes. tags: "vector,experimental" ---

When Vex is enabled, every feature is recorded exactly once per rotation and then reused for panning and zooming via setSceneView(). Toggle the switch to compare the experimental renderer with the standard Canvas 2D path.

Use the buttons to append new plazas (vectorLayer.addFeatures()) or clear the layer entirely (vectorLayer.clear()) and observe how the cached instructions respond.
